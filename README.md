# m2ts-encoder

📖 **見やすい使い方ガイド(Webページ)**: https://tatata17.github.io/m2ts-encoder/

TV録画(`.m2ts` / `.rpls`)を **一覧表示 → 設定を割り当て → まとめてエンコード → チャンネル別に仕分け** できる、Windows用の小さなツールです。
Python(tkinter)で動く **`m2ts_encoder.pyw` 1つだけ** で動作します(インストール不要)。

- 番組名・チャンネル・放送日を一覧表示(rplsinfo.exe で録画データから取得)
- 「おまかせ」で、ファイルごとに音声・字幕・インターレース・放送局を自動判定してエンコード(HEVC / NVENC)
- 複数ファイルを上から順に自動エンコード(キュー)。ログは自動保存
- エンコード結果の自動診断(ノイズ・破損・失敗の疑いを検出)と、デコードノイズ検査
- エンコード済みファイルをチャンネル別フォルダへ自動仕分け
- メニューからワンクリックで最新版へアップデート

---

## 1. 用意するもの

| もの | 説明 |
|---|---|
| Windows 10/11 | |
| Python 3 | 3.9以上を推奨。公式サイトからインストール。インストーラーで **「Add python.exe to PATH」** と、`.pyw` を関連付ける **「py launcher」** にチェックを入れてください |
| ffmpeg / ffprobe | 同じフォルダに置くか、PATHを通す(`ffprobe` は「おまかせ」の自動判定に使います)。入手先: [gyan.dev の Windows 用ビルド](https://www.gyan.dev/ffmpeg/builds/)。**「full」版**を選んでください(ARIB字幕を入れるのに必要な部品は、full版にだけ入っています)。zipの中の `bin` フォルダにある `ffmpeg.exe` と `ffprobe.exe` を使います |
| rplsinfo.exe | 同じフォルダに置くか、PATHを通す(番組名・チャンネル・放送日の取得に使います)。入手先: [rplsinfo152.zip(v1.5.2)](https://github.com/tsukumijima/rplsinfo/releases/download/v1.5.2/rplsinfo152.zip) をダウンロードして解凍し、中の `rplsinfo.exe` を取り出す(配布元: [tsukumijima/rplsinfo](https://github.com/tsukumijima/rplsinfo/releases))。|
| TsSplitter.exe(用意不要) | 録画の途中で本チャンネル⇔サブチャンネルが切り替わるファイルの分割に使います。アプリに埋め込んであり、必要になったときに同じフォルダへ取り出します(自分で置いたものがあれば、そちらを使います)。作者の説明書で再配布が許されています |
| NVIDIAのGPU(推奨) | 既定のエンコード設定は `hevc_nvenc`(NVIDIAのハードウェアエンコード)を使います。無くても、Intel(QSV)・AMD(AMF)・CPU(libx265)でエンコードできます(メニュー「設定」→「エンコーダー」。「自動」なら、使えるものを自動で選びます) |

「PATHを通す」が分からない場合は、ffmpeg と rplsinfo を `m2ts_encoder.pyw` と**同じフォルダに置く**だけで動きます。PATHの設定のしかたは、[こちらの解説(Qiita)](https://qiita.com/shuhey/items/7ee0d25f14a997c9e285)が参考になります。

## 2. 起動のしかた

1. `m2ts_encoder.pyw` をダウンロードして、好きなフォルダに置く
2. 同じフォルダに `rplsinfo.exe`(と、必要なら `ffmpeg.exe` `ffprobe.exe`)を置く
3. `m2ts_encoder.pyw` を **ダブルクリック**(コマンドプロンプトは開きません)
4. 画面上部の「対象フォルダ」が、そのフォルダになり、自動でスキャンが始まります

> 録画ファイルのあるフォルダに `m2ts_encoder.pyw` をコピーして起動すると、そのフォルダが対象になります。
>
> ⚠️ **一覧に何も出ないときは「サブフォルダも検索する」にチェック！** ブルーレイレコーダー等の録画は `〇〇/STREAM/00001.m2ts` のようにフォルダの奥に入っていることが多く、チェックが無いと、このフォルダ直下しか探しません。直下に無くてサブフォルダに録画があるときは、起動時に「ONにしますか？」と確認が出ます。この設定は、次回起動時も覚えています。
> 「ログ」フォルダは `m2ts_encoder.pyw` と同じ場所に、「仕分け」フォルダは対象フォルダの下(既定は `m2ts_encoder.pyw` と同じ場所)に作られます。

## 3. 基本の流れ(3ステップ)

画面は、上から順に「① 対象を選ぶ → ② 設定を決める → ③ 実行」の流れになっています。

### ① 対象を選ぶ
- 一覧の行を **クリック** で選択。**Ctrl+クリック** で1行ずつ追加、**Shift+クリック** で範囲選択(エクスプローラーと同じ操作感です)。矢印キーやShift+矢印キーも使えます。
- **全選択 / 選択解除** ボタン
- **チャンネルで選択**: 左のプルダウンでチャンネルを選び、「このチャンネルを選択」を押すと、そのチャンネルの未変換のファイルがまとめて選ばれます。「変換済みも含める」にチェックを入れると、変換済みも対象になります。
- **番組名で絞り込み**: 一覧の上の入力欄に文字を入れると、一致する行だけが表示されます。スペース区切りで複数語を指定でき(すべて含むものだけ)、ひらがな/カタカナ、全角/半角、大文字/小文字は区別しません。対象は「番組名」と「ファイル名」です。
- 列の見出しをクリックすると、その列で並べ替えできます。
- 上部の「検索対象」で `.m2ts` / `.rpls` の切り替え、「サブフォルダも検索する」で下の階層のフォルダも探します。

### ② どの設定でエンコードするか決める
1. 「適用する設定」のプルダウンから選びます。まずは **「設定｜おまかせ(ファイルごとに自動判定)」** がおすすめです。
2. 行を選んだ状態で **「選択した行に適用」** を押すと、その行に設定が割り当てられます(この時点ではエンコードは始まりません)。
3. 間違えたら **「選択行の設定を解除」**、全部やり直すなら **「すべて解除」**。
4. 割り当てた設定は、エンコードが終わると自動で解除されます(うっかり再エンコードしないため)。

### ③ 実行
- **「エンコード開始」** を押すと、設定を割り当てた行を、一覧の上から順に1つずつエンコードします。
- **「中断」** で止められます。エンコード中のffmpegもまとめて停止し、未完成の出力は削除されます(合体の途中で止めた場合は、1回目の完成品を残します)。
- **「エンコード後にノイズ検査する」**: エンコード後に、元のm2tsをソフト/CUDAの両方でデコードして比べ、ノイズの有無を、番組情報のCSVに記録します(NVIDIAのGPUが必要です)。
- 画面下の **「実行ログ」** に経過が表示されます(▼ボタンで折りたたみ可能)。ログはエンコードごとに「ログ」フォルダへ自動保存されます。

エンコードが終わると、出力は次の名前で、元のm2tsと同じフォルダに保存されます。

```
番組名,放送日.mkv (または .mp4)      例: アニメ「〇〇」#1,20260307.mkv
```

同じ名前のファイルがすでにあるときは、上書きせず `(2)` を付けます。

## 4. エンコード設定

メニュー「設定」→「エンコード設定...」で、チェックボックスから設定を作れます。

- **おまかせ(推奨)**: ファイルごとにffprobeで中身を調べ、次を自動で決めます。
  - 空の字幕・存在しない音声を外す
  - 解説放送の音声(2本目が極端に少ない場合)を判定し、日本語/解説放送のタイトルを付ける
  - 映像より先に途切れる音声・字幕、まばらな字幕(字幕の間が5分以上空く場合)は、エンコード後に元のm2tsから合体する(同時に入れるとエンコードが止まるため)
  - インターレース/プログレッシブを判定(CATVの60pはインターレース解除なし)
  - CATV(カートゥーン等)のモノラル二か国語を、主音声/副音声/主+副に分離
  - 出力形式(字幕があればMKV、なければMP4)
- **手動の設定**: 出力形式(mkv / mp4)、ARIB字幕、音声の扱い、インターレース解除(なし / yadif / bwdif)、QP値、CUDAデコード、hvc1タグなどを自分で選べます。
- 「生成されるffmpegコマンド」の欄で、実際に実行されるコマンドを確認できます。
- 独自の `.bat` を使いたいときは、メニュー「設定」→「バッチファイル管理...」で追加できます。

## 5. 診断とノイズ検査

- エンコードが終わるたびに、ffmpegのログを自動で解析し、**OK / 要確認 / 失敗** を判定します。
  - 一覧の「エンコード診断」列、または行を右クリック→「エンコード診断を見る」で詳細(問題のあった時刻)を確認できます。
  - 録画の先頭・末尾に出る無害なエラーや、一定間隔で出る無害な警告は無視します。
  - 問題の時刻は、その位置から再生して確認できます(VLC・mpv・MPC-HC・PotPlayerは時刻を指定して再生できます。他のソフトは、ファイルを開くだけになります。再生ソフトは、メニュー「設定」→「再生ソフトを選ぶ」で選べます)。
- メニュー「ログ」→「エンコード診断結果を表示(全件)」で、全ファイルの診断を一覧できます。
- **ノイズ検査**: 元のm2tsをソフト/CUDAでデコードして比較します。結果は番組情報のCSVに追記されます(NVIDIAのGPUが必要。無い環境では、実施せずに進みます)。

## 6. チャンネル別に仕分け

エンコード済みのmkv/mp4と、番組情報のCSVを、チャンネル名のフォルダへまとめます。

```
(アプリと同じ場所)/仕分け/チャンネル名/番組名,放送日.mkv
                                        番組名,放送日.csv
```

- 画面の上のタブ「**エンコード済み(mkv/mp4。m2tsを削除済みのものも含む)**」で、m2tsが無くなったmkv/mp4も、CSVのチャンネル名を読んで仕分けられます。
- 「選択した行をチャンネル別に仕分け」「未仕分けをすべて仕分け」のボタンで実行します。
- メニュー「ツール」→「仕分け」からも実行できます。「まとめて仕分け(チャンネル別→作品ごと)」なら、チャンネル別の仕分けのあと、続けて「作品ごとに仕分け」の画面が開きます。

## 7. その他の機能

- **変換済みm2tsを削除**(メニュー「ツール」): 変換済み(mkv/mp4がある)の元m2tsをまとめて削除します。mkv/mp4は削除しません。ノイズ検査が未完了・中断のm2tsは、記録が終わるまで削除の対象になりません。
- **作品ごとに仕分け**(メニュー「ツール」→「仕分け」): 「仕分け/放送局名/」の中を、作品名のフォルダに分けます。別ウインドウの一覧で、ファイルごとに移動先(作品フォルダ・放送局の直下・動かさない)を決められます。作品名は、話数や `[二]` を除いたうえで、同じ放送局の他の番組名と見比べて、複数の回に共通する名前(空白を含めて)を自動で提案します(同じ放送局に2本以上あるものだけ。1本だけの番組は動かしません)。名前が合わないときは「作品フォルダ名を入力」か「作品名の長さを指定」で直せます。手で決めた名前は覚えられ、次回から自動提案に使われます。直前の1回は「元に戻す」で戻せます。
- **二重にエンコードしたファイルを探して削除**(メニュー「ツール」): 変換済みのmkv/mp4から、番組名・放送日・開始時刻が同じものが2本以上あるものを組にして並べ、1本ずつ「残す/削除」を決めてまとめて削除します(対のcsvも一緒。ごみ箱には入りません)。最初は各組で1本だけ残す提案で、長さが違う組は全部残します。
- **切替のある録画の自動分割**(メニュー「設定」、最初からON): 録画の途中で本チャンネル⇔サブチャンネルが切り替わるファイルを見つけて(サービスの切替のほか、録画の先頭に短い別の映像が混ざっている場合も)、`TsSplitter`(番組情報とPMTの切替ごとに分割)で分けてからエンコードします。分けたファイルは一覧の元の行の下に追加され、元のファイルは残ります。分けたファイルのうち、5秒以下の短いものは、ゴミとして自動で削除します。番組名・放送日は元のファイルのものを使うので、出力は同じ名前になり、「(2)」「(3)」の連番が付きます。エンコードに失敗したときも、分割して試しなおします。
- **縦横比を直す**(メニュー「ツール」): 変換済みのmkv/mp4の表示アスペクト比(4:3 / 16:9)だけを、再エンコードなしで書き換えます。「変換済み一覧から選ぶ」「ファイルを追加」、またはドラッグ&ドロップ(`pip install tkinterdnd2` を入れると有効)で追加できます。映像・音声はそのままコピーするので、数秒〜数十秒で終わります。
- **ファイル名の記号を全角に修正**(メニュー「ツール」): 過去の版で禁止文字の代わりに使われていた半角記号(`;` `@` `$` など)が、mkv/mp4(と同名csv)のファイル名に残っている場合に、本来の全角記号へ戻します。
- **一覧をCSVに保存**(メニュー「ファイル」)
- **右クリックメニュー**: 元のファイルを再生 / 元のファイルの場所を開く / エンコード後のファイルを再生 / エンコード後のファイルの場所を開く / エンコード診断を見る / ノイズ検査 / rplsから番組情報を再取得(BDAV形式用)
- **ログ関連**(メニュー「ログ」): エンコードのログは、1つのtxt(`ログ/まとめ_実行ログ.txt`)に自動で追記されます。「ログを管理」で、選んだログを1つのtxtや1件ずつに書き出す・内容を見る・削除できます(Claudeなどに渡すとき便利)。1件ずつ別のtxtで保存する方式にも切り替えられます。「画面下の実行ログをtxtに保存」で、画面の欄の内容もそのまま保存できます。
- **ツールチップ・メニューの説明**: ボタンやチェックボックスにマウスを置いて約1.5秒待つと、説明が表示されます。メニューの項目は、「ヘルプ → メニューの説明」で、全項目の説明を1つの画面で読めます。
- **読み取るフォルダを変える**: 画面上の「フォルダを変更...」で選べます。選んだフォルダは次回も使われ、「このアプリのフォルダに戻す」で既定に戻せます。
- **エンコーダーを選ぶ**(メニュー「設定」→「エンコーダー」): NVIDIA(hevc_nvenc)・Intel(hevc_qsv)・AMD(hevc_amf)・CPU(libx265)から選べます。既定の「自動」は、使えるものを上から順に選びます。
- **再生ソフトを選ぶ**(メニュー「設定」→「再生ソフトを選ぶ」): 右クリックの「再生」や、診断の時刻からの再生に使うソフトを選びます。未指定のときは、VLCが入っていればVLC、無ければWindowsの既定のアプリで開きます。
- **常にCUDAデコードで変換**(メニュー「設定」): VLCなどのプレーヤーでは出ないノイズが、エンコード後に出るときに、ONにするとどのエンコード設定でもCUDA(GPU)でデコードします(NVIDIAのGPUが必要)。

## 8. アップデート

メニュー「**ヘルプ**」→「**アップデートを確認...**」を押します。

1. 新しい版があれば、更新内容が表示されます(細かい修正の版では、「詳しくは更新履歴を見てください」と出ます)
2. 「はい」を押すと、ダウンロード → 置き換え → 自動で再起動します
3. 置き換え前の版は、`%LOCALAPPDATA%\m2ts_encoder\backup\` に自動でバックアップされます(最新5個)
4. エンコード中は更新できません

起動時に自動で確認する設定は、同じメニューの「起動時に更新を確認する」で切り替えられます。新しい版があれば、スキャンの前に案内が出ます。
ダウンロードしたファイルは、版番号と構文を確認してから置き換えるので、通信が途中で切れても今の版は壊れません。

## 9. 設定ファイルの場所

設定(登録したバッチ、再生ソフトのパスなど)は、`%LOCALAPPDATA%\m2ts_encoder\` に小さなJSONとして保存されます。
旧名 `m2ts_info_viewer` の設定フォルダがある場合は、初回起動時に自動で引き継ぎます。

## 10. うまくいかないとき

| 症状 | 対処 |
|---|---|
| 「rplsinfo.exe が見つかりません」 | `rplsinfo.exe` を `m2ts_encoder.pyw` と同じフォルダに置く |
| 一覧に何も出ない | 画面上部の **「サブフォルダも検索する」にチェック**(録画は `〇〇/STREAM/` の奥にあることが多い)。`.m2ts` にもチェックが入っているか確認 |
| 「おまかせ」の判定が出ない | `ffprobe.exe` を同じフォルダに置くか、PATHを通す |
| `.pyw` をダブルクリックしても開かない | Pythonをインストールし直し、`py launcher` と `.pyw` の関連付けにチェックを入れる |
| エンコードの途中で止まって見える | 字幕が非常にまばらな録画では、後から合体する最後の工程で、元のm2tsを読み進めるため、数分かかることがあります。ディスクの読み込みが動いていれば待ってください |
| 診断が「要確認」 | 診断の詳細で時刻を確認し、プレーヤー(VLCなど)で元のm2tsと出力の両方を見て比べる。元が壊れていたら、直せません |
| ログに「`◯◯.mkv を削除できませんでした`」と出て、エンコードに失敗する | そのmkvを開いているソフト(再生ソフトなど)を閉じて、もう一度エンコードします。通常は、前回の失敗や中断で残った `番組.m2ts.mkv` は、エンコード開始時に自動で削除されます |

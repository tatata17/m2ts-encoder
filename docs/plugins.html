プラグイン

m2ts エンコーダーに、手元で拡張機能を足すためのしくみです。このページは、プラグインを置く人・作る人向けの説明です。ふだんの使い方は、使い方ガイドをご覧ください。

  • 本体とは別のファイルなので、本体を更新しても消えません
  • 「ツール」メニューに項目を足せます
  • スキャンの対象にする拡張子を足せます
  • 番組情報や、エンコード後の名前を決められます
⬇ m2ts_encoder.pyw をダウンロード

注意プラグインは、アプリと同じ権限で動く普通のプログラムです。パソコンの中のファイルを読んだり、消したりもできます。中身の分かるものだけを置いてください。

01プラグインとは

プラグインは、Python で書いた小さなファイル(.py)です。決まったフォルダに置いておくと、アプリが起動するときに読み込んで、機能を足します。

アプリ本体(m2ts_encoder.pyw)は、更新のたびに新しいファイルに入れ替わります。プラグインは別のフォルダにあるので、更新しても残ります。

ヒントプラグインを1つも置いていなければ、アプリの動きは何も変わりません。プラグインを自動で入手するしくみは、ありません。

プラグインは、バージョン 2026.11.19.2 から使えます。

02置きかた

  1. プラグインフォルダを開くメニュー「ツール」→「プラグインフォルダを開く」を選びます。フォルダが無ければ、アプリが作ります。
  2. ファイルを置く開いたフォルダに、プラグインの .py を入れます。
  3. アプリを起動しなおすプラグインは、起動するときにだけ読み込まれます。読み込めると、ログの欄に「[プラグイン] ファイル名: 読み込みました」と出ます。

外すときは、フォルダからファイルを消して(または別の場所へ移して)、アプリを起動しなおします。

補足フォルダは、メニューから開くのが確実です。Python の入れかたによっては、実際の場所が %LOCALAPPDATA%\m2ts_encoder\plugins とは別のフォルダになることがあります。

03最小の例

プラグインのファイルには、次の2つを書きます。

書くもの内容
PLUGIN_API_VERSION = 1このプラグインが合わせている、しくみの版です。本体の数と違うと、読み込まれません。今は 1 です。
def register(host):起動するときに、1回だけ呼ばれます。この中で、host を使って機能を登録します。

動きを確かめるための、小さな例です。sample_plugin.py のような名前で保存して、プラグインフォルダに置きます。

PLUGIN_API_VERSION = 1


def register(host):
    host.log("[sample] プラグインを読み込みました")
    host.add_tool_menu_item("サンプルプラグインの挨拶", lambda: host.log("[sample] こんにちは"))
    host.register_scan_extension(".sample", default=True)
    host.register_program_info_provider(
        lambda path: {"program_name": "サンプル番組", "channel": "サンプルch", "broadcast_date": "2026/01/01"}
        if path.lower().endswith(".sample") else None
    )

起動しなおすと、次の3つが起きます。

  • ログの欄に「[sample] プラグインを読み込みました」と出ます。
  • 「ツール」メニューの一番下に「サンプルプラグインの挨拶」が増えます。選ぶと、ログの欄に「[sample] こんにちは」と出ます。
  • 検索対象の .rpls の右に、.sample のチェックボックスが増えます。対象フォルダに .sample で終わるファイルがあれば、番組名「サンプル番組」の行として一覧に出ます。

04host で使えるもの

register(host) に渡される host から、次のものが使えます。

名前内容
host.api_version本体のしくみの版(整数)です。
host.appアプリのメインウインドウです。本体の中身に直接さわれますが、本体の更新で変わることがあります。
host.settings本体と共有の設定(dict)です。自分用の値は、ほかと重ならないキーの名前で入れます。
host.save_settings()設定をファイルに保存します。
host.log(msg)ログの欄に1行出します。どのスレッドから呼んでもかまいません。
host.add_tool_menu_item(label, command)「ツール」メニューに項目を足します。
host.register_scan_extension(ext, default=True)スキャンの対象にする拡張子を足します。
host.register_program_info_provider(fn)番組情報を返す関数を登録します。
host.register_output_name_fallback(fn)エンコード後の名前を決める関数を登録します。

メニューの項目を足す

host.add_tool_menu_item(label, command) は、「ツール」メニューの一番下に項目を足します。command には、引数なしで呼べるものを渡します。

項目を選んだときにプラグインの中でエラーになっても、アプリは止まりません。エラーの内容が、ログの欄に出ます。

スキャンする拡張子を足す

host.register_scan_extension(ext, default=True) は、スキャンの対象にする拡張子を足し、検索対象の並びにチェックボックスを出します。

  • チェックの状態は、アプリが覚えます。default は、まだ覚えていないときの初めの状態です。
  • 拡張子は、. のあとに半角の英数字・_・- を16文字までで書きます。大文字と小文字は区別しません。
  • .m2ts と .rpls は本体が扱うので、登録できません。
  • この拡張子のファイルは、番組情報をまずプラグインに聞きます。そこで取れなかったときだけ、ファイルそのものから番組情報を読みます(2026.11.19.3 から)。対になる rpls は探しません。

補足足した拡張子のファイルは、.m2ts と同じように、録画そのもののファイルとして扱われます。「変換済みm2tsを削除」とノイズ検査の対象にもなります(2026.11.19.4 から)。削除されるのは、変換後の mkv/mp4 が残っていることを確かめられた行だけです。

番組情報を返す

host.register_program_info_provider(fn) で、番組情報を返す関数を登録します。

  • fn(path) は、{"program_name": 番組名, "channel": チャンネル, "broadcast_date": 放送日} の dict を返します。そのファイルについて分からないときは、None を返します。
  • 放送日は 2026/01/01 の形で書きます。空にした項目は、本体の値のままになります。
  • 呼ばれるのは、スキャンのときに、本体が番組名を取れなかったファイルです。.m2ts のファイルでも、番組名が取れなければ呼ばれます。
  • いくつも登録されているときは、登録した順に呼ばれ、最初に dict を返したものが使われます。

エンコード後の名前を決める

host.register_output_name_fallback(fn) で、エンコード後のファイルの名前を決める関数を登録します。

  • fn(row, output_path) は、新しいファイルのパスを返します。決めないときは、None を返します。
  • row は、その行の情報(dict の写し)です。path(元のファイル)、program_name、channel、broadcast_date などが入っています。
  • 呼ばれるのは、エンコードのあとで、本体が録画から番組名を取れなかったときです。本体のふだんの名前付けより前に、登録した順に呼ばれます。
  • 付けたい名前のパスだけを返すと、本体が名前を変えます。同じ名前のファイルがすでにあるときは、変えません。関数の中で名前を変えてから、そのパスを返してもかまいません。

注意番組情報の関数と、名前を決める関数は、画面とは別のスレッドで呼ばれます。関数の中で、ボタンや一覧など、画面の部品にさわらないでください。ログを出すときは host.log を使います。

05読み込みの決まり

  • プラグインフォルダの直下にある .py を、ファイル名の順に読み込みます。フォルダの中のフォルダは見ません。
  • 読み込むのは、アプリを起動したときだけです。最初のスキャンが始まる前に読み込みます。
  • 1つのプラグインがうまく読み込めなくても、アプリと、ほかのプラグインは動きます。
  • 途中でエラーになったプラグインは、そのプラグインだけ無効になります。それまでに登録したメニューの項目やチェックボックスも、取り消されます。

読み込みの結果は、起動したときにログの欄に出ます。

ログの表示意味
読み込みました登録まで終わりました。
読み込みませんでした(PLUGIN_API_VERSION が …)PLUGIN_API_VERSION が無いか、本体の数と違います。
読み込みませんでした(register(host) がありません)register という関数がありません。
エラーのため無効にしました: …読み込みの途中でエラーになりました。「:」のあとが、エラーの内容です。

06困ったとき

こんなとき確かめること
ファイルを置いたのに、何も起きないアプリを起動しなおしましたか。ファイルの名前は .py で終わっていますか。「プラグインフォルダを開く」で開いたフォルダに置きましたか。
「読み込みませんでした」と出るファイルに PLUGIN_API_VERSION = 1 と def register(host): があるかを確かめます。
「エラーのため無効にしました」と出る「:」のあとのエラーの内容を見て、プラグインを直します。直したら、アプリを起動しなおします。
足した拡張子のファイルが、一覧に出ない検索対象の、その拡張子のチェックボックスにチェックが入っているかを確かめます。
アプリの調子がおかしくなったプラグインフォルダを空にして、起動しなおします。それで直れば、プラグインが原因です。
本体を更新したら、プラグインが動かなくなったhost.app から本体の中身に直接さわっていると、本体の更新で動かなくなることがあります。上の表にある host の機能だけを使うと、影響を受けにくくなります。

07ファイルの場所

場所中身
%LOCALAPPDATA%\m2ts_encoder\plugins\プラグインを置くフォルダです。メニュー「ツール」→「プラグインフォルダを開く」で開けます。
%LOCALAPPDATA%\m2ts_encoder\ の設定(JSON)足した拡張子のチェックの状態と、プラグインが host.settings に入れた値が入ります。

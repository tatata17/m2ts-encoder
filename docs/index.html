m2ts エンコーダー

TV録画(.m2ts / .rpls)を、一覧表示 → 設定を割り当て → まとめてエンコード → チャンネル別に仕分けできる、Windows用の小さなツールです。m2ts_encoder.pyw 1つだけで動きます。

⬇ m2ts_encoder.pyw をダウンロード 最新版を確認中…

ヒント: ボタンやチェックボックスにマウスを置いて少し待つと、説明が出ます。メニューの項目は、「ヘルプ → メニューの説明」で、全項目の説明を1つの画面にまとめて読めます。

  • 番組名・チャンネル・放送日を一覧表示
  • 「おまかせ」で音声・字幕・インターレースを自動判定してエンコード
  • 複数ファイルを上から順に自動処理(キュー)
  • エンコード結果を自動診断(ノイズ・破損・失敗)
  • エンコード済みをチャンネル別フォルダへ仕分け
  • メニューからワンクリックで最新版に更新

1用意するもの・起動のしかた

もの用途入手先・備考
Windows 10 / 11動作環境
Python 3アプリ本体を動かす3.9以上を推奨。インストーラーで 「Add python.exe to PATH」 と、.pyw を関連付ける 「py launcher」 にチェックを入れてください。
ffmpeg / ffprobeエンコード本体。ffprobe は「おまかせ」の自動判定に使うgyan.dev の Windows 用ビルド。「full」版を選んでください(ARIB字幕に必要な部品は、full版にだけ入っています)。zipの中の bin フォルダにある ffmpeg.exe と ffprobe.exe を、アプリと同じフォルダに置くか、PATHを通します。
rplsinfo.exe番組名・チャンネル・放送日の取得rplsinfo152.zip(v1.5.2) をダウンロードして解凍し、中の rplsinfo.exe を取り出します(配布元: tsukumijima/rplsinfo の Releases)。同じフォルダに置くか、PATHを通します。
NVIDIAのGPU (推奨)高速なエンコード(hevc_nvenc)、CUDAデコード、ノイズ検査無くても使えます。メニュー「設定」→「エンコーダー」で、Intel(QSV)・AMD(AMF)・CPU(libx265)に切り替えられます。「自動」なら、使えるものを自動で選びます(CPUは遅いです)。
TsSplitter.exe (用意不要)録画の途中で、本チャンネル⇔サブチャンネルが切り替わるファイルの分割アプリに埋め込んであり、必要になったときに同じフォルダへ自動で取り出します。自分で置いたものがあれば、そちらを使います。
tkinterdnd2 (任意)「縦横比を直す」へのドラッグ&ドロップ使いたい場合だけ、コマンドプロンプトで pip install tkinterdnd2 を実行します。入れなくても、ほかの機能はすべて使えます。

入れるもの・入れないもの: 上の表のほかに、Pythonの追加ライブラリ(pip install)は必要ありません(tkinterdnd2 は任意)。Pythonのインストーラーでは「tcl/tk」のチェックを外さないでください(画面の表示に使います)。

「PATHを通す」が分からない場合は、ffmpeg と rplsinfo を m2ts_encoder.pyw と同じフォルダに置くだけで動きます。PATHの設定のしかたは、こちらの解説(Qiita)が参考になります。

  1. m2ts_encoder.pyw をダウンロードして、好きなフォルダ(録画ファイルのあるフォルダでも可)に置く
  2. 同じフォルダに rplsinfo.exe(と、必要なら ffmpeg.exe / ffprobe.exe)を置く
  3. m2ts_encoder.pyw をダブルクリック(コマンドプロンプトは開きません)
  4. 画面上部の「対象フォルダ」がそのフォルダになり、自動でスキャンが始まります

「ログ」フォルダは m2ts_encoder.pyw と同じ場所に、「仕分け」フォルダは対象フォルダの下(既定は m2ts_encoder.pyw と同じ場所)に作られます。

一覧に何も出ないときは「サブフォルダも検索する」にチェック!
ブルーレイレコーダー等の録画は、〇〇/STREAM/00001.m2ts のようにフォルダの奥に入っていることが多く、チェックが無いと、このフォルダ直下しか探しません。 直下に無くてサブフォルダに録画があるときは、スキャン後に「ONにしますか?」と確認が出ます。この設定は、次回起動時も覚えています。

① 対象を選ぶ

  • クリックで選択、Ctrl+クリックで1行ずつ追加、Shift+クリックで範囲選択(エクスプローラーと同じ操作感)。矢印キーやShift+矢印キーも使えます。
  • 全選択 / 選択解除ボタン。
  • チャンネルで選択: プルダウンでチャンネルを選び「このチャンネルを選択」を押すと、そのチャンネルの未変換ファイルがまとめて選ばれます。「変換済みも含める」にチェックすると変換済みも対象になります。
  • 番組名で絞り込み: 入力すると、一致する行だけが表示されます。スペース区切りで複数語(すべて含むものだけ)。ひらがな/カタカナ、全角/半角、大文字/小文字は区別しません。対象は「番組名」と「ファイル名」です。
  • 列の見出しをクリックすると、その列で並べ替えできます。
  • 上部の「検索対象」で .m2ts / .rpls を切り替え、「サブフォルダも検索する」で下の階層も探します。

② どの設定でエンコードするか決める

  1. 「適用する設定」から選びます。まずは 「おまかせ(ファイルごとに自動判定)」 がおすすめです。
  2. 行を選んだ状態で 「選択した行に適用」 を押します(この時点ではまだエンコードは始まりません)。
  3. 間違えたら「選択行の設定を解除」、全部やり直すなら「すべて解除」。

割り当てた設定は、エンコードが終わると自動で解除されます。うっかり再エンコードしないための仕組みです。

③ 実行

  • 「エンコード開始」で、設定を割り当てた行を、一覧の上から順に1つずつエンコードします。
  • 「中断」で止められます。実行中のffmpegもまとめて停止し、未完成の出力は削除します(合体の途中で止めた場合は、1回目の完成品を残します)。
  • 「エンコード後にノイズ検査する」: エンコード後に元のm2tsをソフト/CUDAの両方でデコードして比べ、ノイズの有無を番組情報のCSVに記録します(NVIDIAのGPUが必要です)。
  • 画面下の「実行ログ」に経過が出ます(▼で折りたたみ可)。ログはエンコードごとに「ログ」フォルダへ自動保存されます。

出力は元のm2tsと同じフォルダに、次の名前で保存されます。同名のファイルがあるときは上書きせず (2) を付けます。

番組名,放送日.mkv (または .mp4)     例: アニメ「〇〇」#1,20260307.mkv

3エンコード設定

メニュー「設定」→「エンコード設定...」で、チェックボックスから設定を作れます。

おまかせ(推奨)

ファイルごとにffprobeで中身を調べ、次を自動で決めます。

  • 空の字幕・存在しない音声を外す
  • 解説放送の音声(2本目が極端に少ない場合)を判定し、タイトル「解説放送」を付ける
  • 映像より先に途切れる音声・字幕、まばらな字幕(間が5分以上空く)は、エンコード後に元のm2tsから合体する(同時に入れるとエンコードが止まるため)
  • インターレース / プログレッシブを判定(CATVの60pはインターレース解除なし)
  • CATV(カートゥーン等)のモノラル二か国語を、主音声 / 副音声 / 主+副に分離
  • 出力形式(字幕があればMKV、なければMP4)

エンコーダー(NVIDIAのGPUが無いとき)

メニュー「設定」→「エンコーダー(映像の圧縮に使うもの)」で選びます。エンコード設定(プリセット)にだけ効きます。

選択肢説明
自動(既定)NVIDIA → Intel → AMD → CPU の順に、使える最初のものを選びます。起動時に、短い映像を実際にエンコードして、使えるかを調べます。
NVIDIA(hevc_nvenc)速い。NVIDIAのGPUが必要です。
Intel(hevc_qsv)Intelの内蔵GPU(Quick Sync)。
AMD(hevc_amf)AMDのGPU。
CPU(libx265)どの環境でも動きますが、遅いです。
  • 「使えるエンコーダーを調べる...」で、どれが使えるかを確認できます。
  • 画質の値(QP)は、各エンコーダーの目安に換算します(CPUは QP−4 の CRF など)。エンコーダーによって、同じ値でも画質・ファイルの大きさは少し変わります。
  • CUDAデコード(「常にCUDAデコードで変換」やノイズ検査)は、NVIDIAのGPU専用です。NVIDIA以外では、使わずに(ノイズ検査は実施せずに)進みます。
  • 登録したバッチファイルは、書かれているエンコーダー(多くはhevc_nvenc)のまま実行します。

手動の設定

出力形式(mkv / mp4)、ARIB字幕、音声の扱い、インターレース解除(なし / yadif / bwdif)、QP値、CUDAデコード、hvc1タグなどを自分で選べます。「生成されるffmpegコマンド」欄で、実際に実行されるコマンドを確認できます。独自の .bat を使うときは、メニュー「設定」→「バッチファイル管理...」で追加します。

4診断とノイズ検査

  • エンコードのたびに、ffmpegのログを自動解析して OK / 要確認 / 失敗 を判定します。
  • 一覧の「エンコード診断」列、または行を右クリック →「エンコード診断を見る」で、問題のあった時刻を確認できます。その時刻から再生して見比べられます(VLC・mpv・MPC-HC・PotPlayerは時刻を指定して再生できます。他のソフトは、ファイルを開くだけになります)。
  • 録画の先頭・末尾に出る無害なエラーや、一定間隔で出る無害な警告は無視します。
  • メニュー「ログ」→「エンコード診断結果を表示(全件)」で、全ファイルの診断を一覧できます。
  • ノイズ検査: 元のm2tsをソフト/CUDAでデコードして比較し、結果を番組情報のCSVに追記します(NVIDIAのGPUが必要。無い環境では、実施せずに進みます)。

「要確認」でも、録画そのものが壊れている場合は直せません。VLCなどのプレーヤーで、元のm2tsと出力の両方を見比べて、元が壊れていないか確かめてください。

5チャンネル別に仕分け

エンコード済みのmkv/mp4と番組情報のCSVを、チャンネル名のフォルダへまとめます。

(アプリと同じ場所)/仕分け/チャンネル名/番組名,放送日.mkv
                                       番組名,放送日.csv
  • 上のタブ「エンコード済み(mkv/mp4)」では、m2tsが無くなったmkv/mp4も、CSVのチャンネル名を読んで仕分けられます。
  • 「選択した行をチャンネル別に仕分け」「未仕分けをすべて仕分け」のボタンで実行します。メニュー「ツール」→「仕分け」からも実行できます。

6その他の機能

変換済みm2tsを削除
メニュー「ツール」。変換済み(mkv/mp4がある)の元m2tsをまとめて削除します。mkv/mp4は削除しません。ノイズ検査が未完了・中断のものは対象になりません。
作品ごとに仕分け
メニュー「ツール」→「仕分け」。「まとめて仕分け(チャンネル別→作品ごと)」なら、チャンネル別の仕分けのあと、続けてこの画面が開きます。仕分け済みの放送局フォルダの中を、作品名のフォルダに分けます。ファイルごとに移動先を選べ、直前の1回は元に戻せます。作品名は、同じ放送局の他の番組名と見比べて、複数の回に共通する名前(空白を含めて)を自動で提案します(1本だけの番組は動かしません)。
二重にエンコードしたファイルを探して削除
番組名・放送日・開始時刻が同じ変換済みmkv/mp4を組にして並べ、残す/削除を1本ずつ決めてまとめて削除します。対のcsvも一緒に削除します(ごみ箱には入りません)。
縦横比を直す
変換済みmkv/mp4の4:3 / 16:9表示を、再エンコードなしで書き換えます。一覧から選ぶか、ドラッグ&ドロップ(要 pip install tkinterdnd2)で追加します。
ファイル名の記号を全角に修正
過去の版で半角記号(; @ $ など)になったファイル名を、本来の全角へ戻します。
一覧をCSVに保存
メニュー「ファイル」から。
再生ソフトを選ぶ
メニュー「設定」→「再生ソフトを選ぶ...」。右クリックの「再生」や、診断の時刻からの再生に使うソフトを選びます。未指定のときは、VLCが入っていればVLC、無ければWindowsの既定のアプリで開きます。
右クリックメニュー
元のファイルを再生・場所を開く / エンコード後のファイルを再生・場所を開く / エンコード診断 / ノイズ検査 / rplsから番組情報を再取得(BDAV用)。
ログ
エンコードのログは、1つのtxt(ログ/まとめ_実行ログ.txt)に自動で追記されます。「ログを管理」で、選んだログを1つのtxtや1件ずつに書き出す・内容を見る・削除できます(AIに渡すときに便利)。1件ずつ別のtxtで保存する方式にも切り替えられます。
ツールチップ・メニューの説明
ボタンにマウスを置いて約1.5秒待つと、説明が出ます。メニューの項目は、「ヘルプ → メニューの説明」で一覧できます。
読み取るフォルダを変える
画面上の「フォルダを変更...」で、読み取るフォルダを選べます。選んだフォルダは次回も使われ、「このアプリのフォルダに戻す」で既定に戻せます。
切替のある録画を、TsSplitterで分割してから変換
メニュー「設定」(最初からON)。録画の途中で本チャンネル⇔サブチャンネルが切り替わるファイルは、そのままだとエンコードに失敗することがあります。エンコードの前にファイルを調べ、切替があれば、番組情報とPMTの切替ごとに分けてから、分けたファイルをエンコードします。分けたファイルは一覧の元の行の下に追加され、元のファイルは残ります。切替を見つけられずに失敗したときも、分割して試しなおします。分割に使う TsSplitter.exe は、アプリに埋め込んであり、初めて必要になったときに、同じフォルダへ取り出します。
常にCUDAデコードで変換
メニュー「設定」。VLCなどのプレーヤーでは出ないノイズが、エンコード後に出るときに、ONにするとどのエンコード設定でもCUDA(GPU)でデコードします(NVIDIAのGPUが必要)。

7アップデート

メニュー「ヘルプ」→「アップデートを確認...」を押します。

  1. 新しい版があれば、更新内容が表示されます(細かい修正の版では、「詳しくは更新履歴を見てください」と出ます)。
  2. 「はい」を押すと、ダウンロード → 置き換え → 自動で再起動します。
  3. 置き換え前の版は %LOCALAPPDATA%\m2ts_encoder\backup\ に自動バックアップされます(最新5個)。
  • エンコード中は更新できません。
  • 起動時の自動確認は、同じメニューの「起動時に更新を確認する」で切り替えられます。新しい版があれば、スキャンの前に案内が出ます。
  • ダウンロードしたファイルは、版番号と構文を確認してから置き換えるので、通信が途中で切れても今の版は壊れません。

更新しても残るもの・元に戻したいとき

  • 残るもの: 登録したバッチ、自作のエンコード設定、再生ソフトの指定、対象フォルダ、手で決めた作品名の覚え、ログ、仕分け済みのファイルは、更新しても消えません(アプリの設定は %LOCALAPPDATA%\m2ts_encoder\ に、ログと仕分けは別の場所にあるため、.pyw を置き換えても影響しません)。
  • 元に戻すには: メニュー「ヘルプ」→「旧版のバックアップを管理...」で、古い版を選んで「選んだ版に戻す」ができます。不要になったバックアップは、同じ画面でまとめて削除できます(残す本数は変えられます)。

設定ファイルの場所

%LOCALAPPDATA%\m2ts_encoder\ に、小さなJSONとして保存されます(登録したバッチ、再生ソフトのパスなど)。旧名 m2ts_info_viewer の設定がある場合は、初回起動時に自動で引き継ぎます。

8困ったとき

症状対処
本チャンネル⇔サブチャンネルが切り替わる録画で、エンコードに失敗するメニュー「設定」の「切替のある録画は、TsSplitterで分割してから変換」がONか確認する(ONなら、自動で分割してからエンコードします)。ログの「[分割]」の行に経過が出ます
「rplsinfo.exe が見つかりません」rplsinfo.exe を m2ts_encoder.pyw と同じフォルダに置く
一覧に何も出ない画面上部の「サブフォルダも検索する」にチェック(録画は 〇〇/STREAM/ の奥にあることが多い)。.m2ts にもチェックが入っているか確認
「おまかせ」の判定が出ないffprobe.exe を同じフォルダに置くか、PATHを通す
.pyw をダブルクリックしても開かないPythonを入れ直し、py launcher と .pyw の関連付けにチェックを入れる
エンコードの途中で止まって見える字幕が非常にまばらな録画では、最後の「合体」で元のm2tsを読み進めるため、数分かかることがあります。ディスクの読み込みが動いていれば待ってください。
診断が「要確認」診断の詳細で時刻を確認し、プレーヤー(VLCなど)で元のm2tsと出力の両方を見比べる
ARIB字幕が入らない・字幕のエラーが出るffmpegが「full」版か確認します(essentials版には、字幕の部品が入っていません)。入手先は、上の「用意するもの」を見てください。
プレーヤー(VLCなど)では出ないノイズが、エンコードした動画に出るメニュー「設定」→「常にCUDAデコードで変換」をONにして、もう一度エンコードします(NVIDIAのGPUが必要)。
更新の案内が出ないメニュー「ヘルプ」→「起動時に更新を確認する」がONか確認します。エンコード中は案内を出さず、ログに表示するだけです。
ログに「◯◯.mkv を削除できませんでした」と出て、エンコードに失敗するそのmkvを開いているソフト(再生ソフトなど)を閉じて、もう一度エンコードします。通常は、前回の失敗や中断で残った 番組.m2ts.mkv は、エンコード開始時に自動で削除されます。

アプリが作るファイル

アプリが作るファイルの場所です。どれも、消しても録画やエンコード済みファイルには影響しません(設定を消すと、設定が初期状態に戻ります)。

場所中身
m2ts_encoder.pyw と同じフォルダログ/(エンコードのログ。既定は まとめ_実行ログ.txt の1つ)、仕分け/(チャンネル別・作品ごとの仕分け先)。ffmpeg.exe や rplsinfo.exe を置く場所でもあります。
録画ファイルの隣番組情報とノイズ検査の結果を書いたCSV(番組名.m2ts.csv など)。エンコードしたmkv/mp4も、元のm2tsの隣にできます。
%LOCALAPPDATA%\m2ts_encoder\設定(JSON)、backup\(旧版のバックアップ)、作品ごとの仕分けを元に戻すための記録。

対象フォルダを「フォルダを変更...」で変えた場合も、ログ・仕分け・ffmpegの置き場所は m2ts_encoder.pyw のフォルダのままです。ただし「仕分け」フォルダだけは、選んだ対象フォルダの下に作られます。

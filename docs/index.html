m2ts エンコーダー

TV録画(.m2ts / .rpls)を、一覧表示 → 設定を割り当て → まとめてエンコード → チャンネル別に仕分けできる、Windows用の小さなツールです。m2ts_encoder.pyw 1つだけで動きます。

⬇ m2ts_encoder.pyw をダウンロード 最新版を確認中…
  • 番組名・チャンネル・放送日を一覧表示
  • 「おまかせ」で音声・字幕・インターレースを自動判定してエンコード
  • 複数ファイルを上から順に自動処理(キュー)
  • エンコード結果を自動診断(ノイズ・破損・失敗)
  • エンコード済みをチャンネル別フォルダへ仕分け
  • メニューからワンクリックで最新版に更新

1用意するもの・起動のしかた

もの説明
Windows 10 / 11
Python 33.9以上を推奨。インストーラーで 「Add python.exe to PATH」 と、.pyw を関連付ける 「py launcher」 にチェックを入れてください。
ffmpeg / ffprobeアプリと同じフォルダに置くか、PATHを通します。ffprobe は「おまかせ」の自動判定に使います。
rplsinfo.exe同じフォルダに置くか、PATHを通します。番組名・チャンネル・放送日の取得に使います。
NVIDIAのGPU既定のエンコード設定は hevc_nvenc(NVIDIAのハードウェアエンコード)を使います。
  1. m2ts_encoder.pyw をダウンロードして、好きなフォルダ(録画ファイルのあるフォルダでも可)に置く
  2. 同じフォルダに rplsinfo.exe(と、必要なら ffmpeg.exe / ffprobe.exe)を置く
  3. m2ts_encoder.pyw をダブルクリック(コマンドプロンプトは開きません)
  4. 画面上部の「対象フォルダ」がそのフォルダになり、自動でスキャンが始まります

「ログ」「仕分け」フォルダも、m2ts_encoder.pyw と同じ場所に作られます。

一覧に何も出ないときは「サブフォルダも検索する」にチェック!
ブルーレイレコーダー等の録画は、〇〇/STREAM/00001.m2ts のようにフォルダの奥に入っていることが多く、チェックが無いと、このフォルダ直下しか探しません。 直下に無くてサブフォルダに録画があるときは、スキャン後に「ONにしますか?」と確認が出ます。この設定は、次回起動時も覚えています。

① 対象を選ぶ

  • クリックで選択、Ctrl+クリックで1行ずつ追加、Shift+クリックで範囲選択(エクスプローラーと同じ操作感)。矢印キーやShift+矢印キーも使えます。
  • 全選択 / 選択解除ボタン。
  • チャンネルで選択: プルダウンでチャンネルを選び「このチャンネルを選択」を押すと、そのチャンネルの未変換ファイルがまとめて選ばれます。「変換済みも含める」にチェックすると変換済みも対象になります。
  • 番組名で絞り込み: 入力すると、一致する行だけが表示されます。スペース区切りで複数語(すべて含むものだけ)。ひらがな/カタカナ、全角/半角、大文字/小文字は区別しません。対象は「番組名」と「ファイル名」です。
  • 列の見出しをクリックすると、その列で並べ替えできます。
  • 上部の「検索対象」で .m2ts / .rpls を切り替え、「サブフォルダも検索する」で下の階層も探します。

② どの設定でエンコードするか決める

  1. 「適用する設定」から選びます。まずは 「おまかせ(ファイルごとに自動判定)」 がおすすめです。
  2. 行を選んだ状態で 「選択した行に適用」 を押します(この時点ではまだエンコードは始まりません)。
  3. 間違えたら「選択行の設定を解除」、全部やり直すなら「すべて解除」。

割り当てた設定は、エンコードが終わると自動で解除されます。うっかり再エンコードしないための仕組みです。

③ 実行

  • 「エンコード開始」で、設定を割り当てた行を、一覧の上から順に1つずつエンコードします。
  • 「中断」で止められます。実行中のffmpegもまとめて停止し、未完成の出力は削除します(合体の途中で止めた場合は、1回目の完成品を残します)。
  • 「エンコード後にノイズ検査する」: エンコード後に元のm2tsをソフト/CUDAの両方でデコードして比べ、ノイズの有無を番組情報のCSVに記録します。
  • 画面下の「実行ログ」に経過が出ます(▼で折りたたみ可)。ログはエンコードごとに「ログ」フォルダへ自動保存されます。

出力は元のm2tsと同じフォルダに、次の名前で保存されます。同名のファイルがあるときは上書きせず (2) を付けます。

番組名,放送日.mkv (または .mp4)     例: アニメ「〇〇」#1,20260307.mkv

3エンコード設定

メニュー「設定」→「エンコード設定...」で、チェックボックスから設定を作れます。

おまかせ(推奨)

ファイルごとにffprobeで中身を調べ、次を自動で決めます。

  • 空の字幕・存在しない音声を外す
  • 解説放送の音声(2本目が極端に少ない場合)を判定し、タイトル「解説放送」を付ける
  • 映像より先に途切れる音声・字幕、まばらな字幕(間が5分以上空く)は、エンコード後に元のm2tsから合体する(同時に入れるとエンコードが止まるため)
  • インターレース / プログレッシブを判定(CATVの60pはインターレース解除なし)
  • CATV(カートゥーン等)のモノラル二か国語を、主音声 / 副音声 / 主+副に分離
  • 出力形式(字幕があればMKV、なければMP4)

手動の設定

出力形式(mkv / mp4)、ARIB字幕、音声の扱い、インターレース解除(なし / yadif / bwdif)、QP値、CUDAデコード、hvc1タグなどを自分で選べます。「生成されるffmpegコマンド」欄で、実際に実行されるコマンドを確認できます。独自の .bat を使うときは、メニュー「設定」→「バッチファイル管理...」で追加します。

4診断とノイズ検査

  • エンコードのたびに、ffmpegのログを自動解析して OK / 要確認 / 失敗 を判定します。
  • 一覧の「エンコード診断」列、または行を右クリック →「エンコード診断を見る」で、問題のあった時刻を確認できます。VLCでその位置から再生して見比べられます。
  • 録画の先頭・末尾に出る無害なエラーや、一定間隔で出る無害な警告は無視します。
  • メニュー「ログ」→「エンコード診断結果を表示(全件)」で、全ファイルの診断を一覧できます。
  • ノイズ検査: 元のm2tsをソフト/CUDAでデコードして比較し、結果を番組情報のCSVに追記します。

「要確認」でも、録画そのものが壊れている場合は直せません。VLCで元のm2tsと出力の両方を見比べて、元が壊れていないか確かめてください。

5チャンネル別に仕分け

エンコード済みのmkv/mp4と番組情報のCSVを、チャンネル名のフォルダへまとめます。

(アプリと同じ場所)/仕分け/チャンネル名/番組名,放送日.mkv
                                       番組名,放送日.csv
  • 上のタブ「エンコード済み(mkv/mp4)」では、m2tsが無くなったmkv/mp4も、CSVのチャンネル名を読んで仕分けられます。
  • 「選択した行をチャンネル別に仕分け」「未仕分けをすべて仕分け」のボタンで実行します。メニュー「ツール」からも実行できます。

6その他の機能

変換済みm2tsを削除
メニュー「ツール」。変換済み(mkv/mp4がある)の元m2tsをまとめて削除します。mkv/mp4は削除しません。ノイズ検査が未完了・中断のものは対象になりません。
縦横比を直す
変換済みmkv/mp4の4:3 / 16:9表示を、再エンコードなしで書き換えます。一覧から選ぶか、ドラッグ&ドロップ(要 pip install tkinterdnd2)で追加します。
ファイル名の記号を全角に修正
過去の版で半角記号(; @ $ など)になったファイル名を、本来の全角へ戻します。
一覧をCSVに保存

7アップデート

メニュー「ヘルプ」→「アップデートを確認...」を押します。

  1. 新しい版があれば、更新内容が表示されます。
  2. 「はい」を押すと、ダウンロード → 置き換え → 自動で再起動します。
  3. 置き換え前の版は %LOCALAPPDATA%\m2ts_encoder\backup\ に自動バックアップされます(最新5個)。
  • エンコード中は更新できません。
  • 起動時の自動確認は、同じメニューの「起動時に更新を確認する」で切り替えられます。
  • ダウンロードしたファイルは、版番号と構文を確認してから置き換えるので、通信が途中で切れても今の版は壊れません。

設定ファイルの場所

%LOCALAPPDATA%\m2ts_encoder\ に、小さなJSONとして保存されます(登録したバッチ、VLCのパスなど)。旧名 m2ts_info_viewer の設定がある場合は、初回起動時に自動で引き継ぎます。

症状対処
「rplsinfo.exe が見つかりません」rplsinfo.exe を m2ts_encoder.pyw と同じフォルダに置く
一覧に何も出ない画面上部の「サブフォルダも検索する」にチェック(録画は 〇〇/STREAM/ の奥にあることが多い)。.m2ts にもチェックが入っているか確認
「おまかせ」の判定が出ないffprobe.exe を同じフォルダに置くか、PATHを通す
.pyw をダブルクリックしても開かないPythonを入れ直し、py launcher と .pyw の関連付けにチェックを入れる
